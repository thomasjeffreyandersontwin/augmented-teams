PHASE 1: CARD SYSTEM (3-4 hours)
================================================================================
Replace flat sections with layered card containers.

[ ] 1. Define CSS card classes
      .card-primary   - Main containers (Behavior Action Status, Scope)
      .card-secondary - Nested sections (shape, prioritization)
      .card-item      - Individual list items

[ ] 2. Card styling
      - border-radius: 6px (primary), 4px (secondary), 3px (items)
      - box-shadow: 0 2px 8px rgba(0,0,0,0.3) for primary cards
      - border: 1px solid rgba(255,255,255,0.08)

[ ] 3. Background depth layers
      --bg-base:     #1e1e1e  (panel background)
      --bg-elevated: #252526  (primary cards)
      --bg-surface:  #2d2d2d  (secondary cards)

[ ] 4. Active state indicator
      - 3px left border in accent color
      - Subtle accent background tint: rgba(accent, 0.1)

================================================================================
PHASE 2: THEMING SYSTEM (2-3 hours)
================================================================================
Enable client-specific color schemes.

[ ] 1. Create CSS custom properties structure
      :root {
        --accent-hue: 30;           /* Orange default */
        --accent-saturation: 90%;
        --accent-lightness: 55%;
        
        /* Derived colors */
        --accent: hsl(var(--accent-hue), var(--accent-saturation), var(--accent-lightness));
        --accent-dim: hsl(...);
        --accent-glow: hsl(...);
        --accent-bg: hsla(..., 0.1);
      }

[ ] 2. Define client theme presets
      [data-theme="default"]   { --accent-hue: 30;  }  /* Orange */
      [data-theme="deloitte"]  { --accent-hue: 145; }  /* Green */
      [data-theme="sproch"]    { --accent-hue: 0;   }  /* Red */
      [data-theme="microsoft"] { --accent-hue: 200; }  /* Blue */

[ ] 3. Theme switching mechanism
      - Add data-theme attribute to root container
      - Store preference in VS Code settings or local storage
      - Provide theme selector in panel header or settings

[ ] 4. Test all states with each theme
      - Hover, active, focus, disabled
      - Ensure sufficient contrast ratios

================================================================================
PHASE 3: TYPOGRAPHY & SPACING (2 hours)
================================================================================
Consistent sizing and visual rhythm.

[ ] 1. Define spacing scale
      --space-xs: 4px;
      --space-sm: 8px;
      --space-md: 12px;
      --space-lg: 16px;
      --space-xl: 24px;

[ ] 2. Typography scale
      11px - metadata, timestamps
      12px - body text, list items
      13px - section headers
      16px - panel title
      
[ ] 3. Font stack
      Primary: inherit from VS Code (respects user settings)
      Monospace: var(--vscode-editor-font-family)

[ ] 4. Line heights
      Compact (lists): 1.4
      Comfortable (text blocks): 1.6

================================================================================

Replace text-based status with visual indicators.

[ ] 1. Status dot system
      Pending:     ○ (hollow circle) or gray dot

[ ] 2. Progress indicators
