# Quick Installation Guide

## Building and Installing the Extension

### Step 1: Build
```powershell
cd agile_bot/bots/base_bot/src/display_panel/extension
.\rebuild.ps1
```

### Step 2: Uninstall Old Version (if exists)

**For Cursor:**
```powershell
cursor --uninstall-extension agilebot.repl-status-panel
```

**For VS Code:**
```powershell
code --uninstall-extension agilebot.repl-status-panel
```

### Step 3: Install New Version

**For Cursor:**
```powershell
cursor --install-extension repl-status-panel-0.11.0.vsix
```

**For VS Code:**
```powershell
code --install-extension repl-status-panel-0.11.0.vsix
```

### Step 4: Reload Window

**IMPORTANT:** You must reload the window for changes to take effect!

- Press `Ctrl+Shift+P`
- Type "Developer: Reload Window"
- Press Enter

## Common Issues

### Changes not appearing
- Make sure you're installing to the correct IDE (Cursor vs VS Code)
- Always reload the window after installation
- Check the extension is actually installed: `cursor --list-extensions`

### Extension not found
- Verify you're in the correct directory
- Check the .vsix file was generated by rebuild.ps1

### Version conflicts
- Always uninstall the old version before installing a new one
- Use the same version number in both uninstall and install commands
